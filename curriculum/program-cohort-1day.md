# Program Cohort — 1 Day

**Track:** Program (hospitals, practices, residency/fellowship programs) · **Format:** 1 day, on-site, group size varies (residency cohorts often run 15–30+) · **Price:** request proposal

Same peer-pairing structure as Applicant Cohort Seat, using the physician
scenarios (`diagnosis_delivery`, `bad_news`, `refusal`, `angry_family`
from `shared/prompts/scenarios.py`) instead of the applicant ones. Scale
notes below matter more here than for the applicant cohort — hospital
groups are often bigger than one facilitator can individually film.

## Pre-session checklist

- Confirm group size with the program contact before finalizing the
  agenda — above ~12 people, the individual filmed baseline/final blocks
  need to run in parallel (see Scaling below), not one at a time.
- Printed scenario cards covering all four physician scenarios and all
  four P-modes, enough copies for every pair to cycle through several.
- Rubric card per participant.
- `CohortRoster` submission (participant names + room/AV needs) should
  already be in from the sponsor before delivery day — confirm it arrived;
  don't discover the room setup on arrival.

**Scaling above ~12 people:** split into clusters of 4–6 for the baseline
and final filming blocks, each cluster filming each other on a phone while
you circulate and spot-check rather than watching every single encounter
yourself. The teaching blocks stay whole-group regardless of size.

---

## Run-of-show

**9:00–9:20 — Group welcome**
Introduce the day and the method to the full cohort. Explain the format:
everyone gets filmed twice, the rest of the day is peer drilling with you
circulating.

**9:20–10:15 — Filmed baseline encounters**
One at a time for small groups; parallel clusters for larger ones (see
Scaling above).

**10:15–10:30 — Break**

**10:30–11:15 — Teach: Read + Pick the P**
Whole group, same content as Physician Private's Day 1 modules, compressed
into one block — same as the applicant cohort's approach.

**11:15–12:00 — Paired drilling: Read + Pick the P**
Scenario cards, pairs rotate through 2 encounters each side.

**12:00–1:00 — Lunch**

**1:00–1:30 — Teach: Speak**
Five dials, group demonstration format rather than individual isolation.

**1:30–2:15 — Paired drilling: Speak focus**
Partner's job: call out fillers and broken eye contact after each encounter.

**2:15–2:30 — Break**

**2:30–3:00 — Teach: Ask + Shift (combined)**
Compressed, same as the applicant cohort — explain both, flag that the
next round includes unannounced shifts.

**3:00–3:30 — Paired drilling: full integration with shifts**
Cards marked for a mid-encounter P-mode switch.

**3:30–4:15 — Filmed final encounters**
Same format as the morning baseline block.

**4:15–4:30 — Close**
Group thank-you, explain what arrives next (individual scorecards, cohort
summary for the program). Individual numbers stay 1:1 — don't read anyone's
score to the group.
